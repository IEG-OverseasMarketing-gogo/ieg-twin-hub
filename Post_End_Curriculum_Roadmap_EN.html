3-Layer Architecture

A phased SKU structure that lets partners adopt based on their existing equipment ownership.

LAYER 1

SW Simulator

PC/tablet-based 3D process simulation. A complete loop from parameter manipulation → defect generation → diagnosis, with no physical equipment required. Emotii Arabic UI supported.

Lite — Standalone SW license
LAYER 2

Real-Equipment Integration

Connects to IEG's physical equipment (Die Bonder · Wire Bonder · Mold Press · Dicing · Bond Tester) via OPC-UA/EtherCAT, so Layer 1 recipes can be verified on real hardware.

Standard — L1 + equipment bundle
LAYER 3

Automated Assessment · Certification

Auto-generates I/O lists, Pass/Fail matrices, SPC control charts, and competency rubrics. SCORM LMS integration, with TVTC certification consulting included.

Full — L1 + L2 + L3 + TVTC linkage

BTEC Mapping — Gap Closure Status

How the six gaps identified in the original mapping document are addressed by the simulator design.

✓ Gap 1 — Industrial Network Protocols

Closed by SA-L1-04 (EtherCAT vision-sensor simulation) + SA-L2-01 (real-signal monitoring). A Profinet simulation module is planned.

✓ Gap 2 — Analog I/O & PID Control

Closed by MO-L1-02 (PID gain tuning) + MO-L2-01 (real signal acquisition from the Mold Press). Temperature-profile comparison analysis is the key evidence artifact.

✓ Gap 3 — SFC Software Design Tools

Two dedicated SFC-design sessions built around SA-L1-01. The Die Bond → Wire Bond → Mold → Eject sequence is designed as an SFC, then verified at L2.

✓ Gap 4 — Cleanroom Panel Design Constraints

A shared theory session across DB/WB/MO covering ESD-safe wiring, sealing ratings, and particle-reduction design, with an IEG real cleanroom-panel case study.

✓ Gap 5 — Individual Performance Self-Assessment Rubric

The L3 assessment system embeds a bilingual (Arabic/English) self-assessment form across four axes: technical competency, time management, communication, and industry readiness.

✓ Gap 6 — BTEC Evidence Formatting

L3's automated reports generate I/O lists, test matrices, and observation records that match BTEC Aim A–D standards, with PDF export.
